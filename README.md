# AMR Awareness 2026 — Interactive Story

A mobile-first, step-by-step illustrated story about antibiotic resistance through target modification.

## Files

- `index.html` — page structure
- `css/style.css` — layout, responsive styling and transitions
- `js/story.js` — scene text, image paths and accessibility descriptions
- `js/app.js` — Next/Back controls, progress, keyboard and swipe navigation
- `assets/` — scene artwork crops taken from the generated poster artwork supplied in this conversation

## Run / publish

This is a static website. No build tools or server-side code are required.

1. Upload the contents of this folder to the root of your GitHub Pages repository (the folder contents, not the containing folder).
2. Keep the paths exactly as shown: `css/`, `js/`, and `assets/` beside `index.html`.
3. Open the GitHub Pages URL and refresh after deployment.

## Controls

- Next / Back buttons
- Swipe left or right on touchscreens
- Left / right arrow keys on a keyboard
- Motion toggle for visitors who prefer reduced animation

## Scientific note

The story depicts genetic variation and selection. It does not suggest that bacteria consciously decide to modify their targets. Antibiotic exposure selects for resistant bacteria when susceptible bacteria are killed or inhibited and resistant variants survive and multiply.

## Artwork note

The scene artwork is cropped from the poster illustration generated for this project, so the website and poster share the same visual identity. The artwork is used as illustrated scene panels with gentle camera motion and transitions; it is not a fully rigged, independently animated character model.
